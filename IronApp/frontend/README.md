## Frontend Setup

## Prerequisites

- Node.js (version 16 or higher)
- npm or yarn package manager

## Setup & Installation

1. Navigate to the frontend directory:
   ```bash
   cd IronApp/frontend
   ```

2. Install all dependencies:
   ```bash
   npm install
   ```


## Dependencies

### Core React Libraries
- **[React](https://react.dev/)** ^19.0.0 - JavaScript library for building user interfaces
- **[React DOM](https://react.dev/)** ^19.0.0 - React package for working with the DOM
- **[React Router DOM](https://reactrouter.com/)** ^7.2.0 - Declarative routing for React applications

### UI & Styling
- **[Tailwind CSS](https://tailwindcss.com/)** ^4.1.4 - Utility-first CSS framework
- **[Lucide React](https://lucide.dev/)** ^0.507.0 - Beautiful & consistent icon toolkit
- **[Framer Motion](https://www.framer.com/motion/)** ^12.9.4 - Production-ready motion library for React

### Data Visualization & Calendar
- **[Recharts](https://recharts.org/)** ^2.15.3 - Composable charting library built on React components
- **[React Calendar](https://github.com/wojtekmaj/react-calendar)** ^5.1.0 - Ultimate calendar for your React app

### HTTP & Authentication
- **[Axios](https://axios-http.com/)** ^1.8.1 - Promise-based HTTP client for the browser and Node.js
- **[JWT Decode](https://github.com/auth0/jwt-decode)** ^4.0.0 - Library to decode JWT tokens
